# 応募者プロフィール(Claude が提案文を書くときに参照)

> 下書き済み。【要確認】の箇所だけ直してください。ここに無い経歴を Claude が提案文に書くことはありません。

## 基本
- 表示名:【要確認】
- ひとことで:鋳造の現場20年。現在は Claude Code を使ってホームページ制作・業務の自動化を請け負っています。
- 稼働できる時間:【要確認】例)平日夜2時間・土日4時間
- 連絡の返信目安:【要確認】例)24時間以内

## 経歴・実績(事実だけ)
- 鋳造会社での現場経験 約20年(工程・品質・不良の話が分かる)
- 鋳造会社のホームページ制作(1件・制作中/完成後に事例化予定)
- 【要確認】ほかに書ける実績があれば

## できること(提案文に書いてよい範囲)
- ホームページ・LP制作(HTML/CSS/JavaScript)、既存ページの修正
- 文章作成:会社案内、求人原稿、製品説明、マニュアル
- 製造業・町工場向けの記事、業界用語の分かる原稿
- Excel/スプレッドシートの整理、簡単な関数・マクロ・GAS
- 簡単な業務自動化(Python スクリプト等)
- 日本語⇔英語の翻訳(AI を使い、自分で確認)

## 単価の目安
- 最低ライン:時給換算 【要確認】円(これを下回る案件は見送り)
- 文字単価:【要確認】円/字 以上
- ホームページ制作:【要確認】円〜

## AI利用の申告
- 提案文に「AI(Claude)を活用して作業し、内容は自分で確認して納品します」の一文を入れる:**入れる**
  (入れない場合は「入れない」に書き換え。※発注者が AI 不可と書いている案件はどちらにしても応募しません)

## 文体
- 丁寧だが堅すぎない。です・ます。
- 盛らない。できないことは書かない。
- 長すぎない(本文 300〜500字目安)。

## NG(応募しない)
- 電話・ビデオ会議が必須
- 顔出し・本名公開が必須
- 【要確認】ほかにあれば
