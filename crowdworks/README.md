# クラウドワークス 代行ワークフロー

Claude(Claude Code)が「案件の選別 → 提案文の下書き → 受注後の作業 → 納品メッセージの下書き」までを担当し、
**あなたは「貼る・読む・押す」だけ**にするための仕組み。

```
 あなた                       Claude
 ─────────────────────        ─────────────────────────────────
 ① 案件ページをコピー  ──▶  ② 選別(できる/できない・時給換算)
                              ③ 提案文を下書き
 ④ 読んで直して応募    ◀──
 ⑤ 受注したら知らせる  ──▶  ⑥ 実作業(成果物を jobs/<案件>/deliverables/ に作る)
                              ⑦ 要件チェック表+納品メッセージ下書き
 ⑧ 中身を確認して納品  ◀──
```

## なぜ「応募ボタン」と「納品ボタン」はあなたが押すのか

ここは意図的に自動化していません。

- **規約**:クラウドワークスの利用規約は、ボット等による自動アクセスや、同じ文面の大量応募を禁じる方向の内容です(最新の条文は必ずご自身で確認してください)。ログイン情報をスクリプトに渡して自動応募させると、アカウント停止のリスクがあります。停止されると実績・評価ごと失います。
- **責任**:契約の当事者はあなたです。「中身を見ずに出したものが間違っていた」は、あなたの評価に直撃します。
- **AI利用の申告**:「AI使用不可」と書く発注者もいます。提案文には、AIを使う場合はそう明記する一文を入れる設計にしています(外したい場合は profile.md で設定)。

自動化の効果が大きいのは「考える・書く・作る」部分で、そこは全部 Claude がやります。押すのは1案件あたり数クリックです。

## 使い方

### 0. 最初に一度だけ
`crowdworks/profile.md` を埋める(下書き済み。希望単価・NG条件・文体だけ確認)。

### 1. 案件を登録する
クラウドワークスの案件ページを開き、本文〜条件〜発注者情報までを全部コピーして、Claude Code にこう言う:

```
/crowdworks-apply
(ここに案件ページを貼る)
```

複数件まとめて貼ってもOK(「---」で区切る)。Claude が案件ごとにフォルダを作り、
- `job.md` … 案件の原文と判定結果(GO / 保留 / 見送り と理由)
- `proposal.md` … GO の案件だけ、提案文の下書き

を作ります。

### 2. 応募する
`proposal.md` を読んで、気になるところを直して、クラウドワークス上で応募。
応募したら「〇〇に応募した」と一言伝えるか、`python3 crowdworks/cw.py status <案件ID> applied`。

### 3. 受注したら
```
/crowdworks-work <案件ID>
(発注者からの追加メッセージや資料があれば貼る)
```
Claude が `deliverables/` に成果物を作り、`delivery.md` に「要件チェック表」と「納品メッセージ案」をまとめます。
発注者とのやりとりが発生したら、そのメッセージを貼れば返信案も作ります。

### 4. 確認して納品
`delivery.md` のチェック表を見て、成果物を開いて確認 → クラウドワークスで納品。
`python3 crowdworks/cw.py status <案件ID> delivered`

### 一覧を見る
```
python3 crowdworks/cw.py list
```

## 状態の流れ

| 状態 | 意味 | 誰が進める |
|---|---|---|
| `screened` | 判定済み(GO/保留/見送り は job.md の `verdict`) | Claude |
| `proposed` | 提案文の下書きあり | Claude |
| `applied` | 応募した | あなた |
| `awarded` | 受注した | あなた |
| `working` | 作業中 | Claude |
| `review` | 成果物と納品案ができた。あなたの確認待ち | Claude |
| `delivered` | 納品した | あなた |
| `done` / `lost` / `skipped` | 完了 / 不採用 / 見送り | どちらでも |

## Claude が取りにいく案件・取らない案件

詳しくは `.claude/skills/crowdworks-apply/SKILL.md` の判定基準。ざっくり:

- **取る**:成果物がファイルで完結するもの。記事・文章作成、文字起こし済みテキストの整形、翻訳(日英)、データ整理・Excel/スプレッドシート、簡単なWebページ・LP・HTML/CSS修正、Python/GASなどの小さなスクリプト、商品説明文、マニュアル作成。鋳造・製造業の知識が効く案件は優先。
- **取らない**:電話・対面・顔出し・常駐、あなた本人の実体験が要るもの(体験談・口コミ・レビュー投稿)、ステマ・やらせ・アカウント作成代行、資格が要るもの、「AI使用不可」の案件、タスク形式の大量単純作業(単価が低すぎる)、外部への連絡先誘導がある案件。
